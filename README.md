# AI Crisis

Інтерактивний візуальний прототип кризового сценарію, раунди 7–12.

## Запуск

Потрібен Node.js 22.12+.

```sh
npm install
npm run dev
```

Відкрити локальну адресу, надруковану Vite. `npm test` перевіряє симуляцію, `npm run build` створює `dist/`.

## Як грати

Мета — м’яка посадка після 12-го раунду: довіра від 45%, кожна галузь від 75% послуг,
середній резерв від 20%. Ці три умови з поточними значеннями завжди видно в кабінеті.

Щораунду розподіліть обчислення кнопками мінус і плюс та оберіть один указ. Для
перепідготовки й ручного режиму оберіть галузь. Блок «Прогноз раунду» показує, що
станеться після підпису: довіра, бюджет, обчислення на наступний раунд, чи буде
завершено етап будівництва. Підпишіть указ і спостерігайте за 16-секундним періодом
у місті; доступні пауза, подвійна швидкість і перехід до підсумків.

Що тисне на гравця:

- Імпортна квота зменшується на 2 щораунду. Без власного дата-центру або угоди обчислень не вистачить.
- Лікарні, держпослуги й освіта рухають довіру. Довіра 25% або нижче — відставка.
- Промисловість і логістика дають дохід. Від’ємний бюджет — банкрутство.
- Дата-центр (55, три етапи) будується лише коли ІТ і логістика працюють від 75%.
- Угода з корпорацією дає +10 обчислень назавжди, але коштує 10 щораунду, резерву й довіри. Третя угода — поразка.
- Ручний режим безкоштовний для бюджету, але забирає 3 довіри.
- Подія раунду (сплеск попиту в галузі, урізана квота, разова поставка) визначається сідом партії.

Сід видно в кабінеті й газеті. `?seed=123` в адресі запускає ту саму партію, після
фіналу її можна переграти кнопкою.

## Баланс і тести

Усі числа сценарію — константи на початку `src/core/game.ts`. `npm test` запускає
юніт-тести симуляції та `src/core/balance.test.ts`: боти з `src/core/bots.ts`
проганяють стратегії на 20 сідах і перевіряють, що спам ручним режимом програє,
без розподілу обчислень виграти не можна, жоден простий рецепт не гарантує перемогу,
а переможна лінія існує на кожному сіді.

## Межі поточної версії

Один сценарій дефіциту, сім галузей, чотири укази, шість типів подій. Фази буму,
виборів, колоди пропозицій та збережень ще немає. Перезавантаження починає нову партію.
Місто використовує ілюстрацію з анімованими ефектами та показниками.
Окремі будівельні спрайти й повноцінні анімації станів залишаються наступним етапом.

TypeScript strict, Vite, Vitest. Симуляція в `src/core/game.ts` незалежна від DOM.
Мобільні збірки через Capacitor можна додати після перевірки на пристроях.
Наразі перевіряється адаптивна вебверсія, нативних iOS/Android-проєктів ще немає.

Графіка створена вбудованим ImageGen. Місто — європейська столиця-діорама на заході
сонця із сімома галузями, без інтерфейсу. Картки — чотири гравюри на пергаменті,
що зображують перепідготовку, дата-центр, корпоративну угоду та ручну працю.
